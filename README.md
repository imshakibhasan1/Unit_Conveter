## 🌟 Features

- **Multi-Unit Conversion**: Automatically converts values for:
  - **Length**: Meters ↔ Feet
  - **Volume**: Liters ↔ Gallons
  - **Mass**: Kilograms ↔ Pounds
- **Responsive Design**: Custom CSS layout optimized for both mobile devices and desktop views.
- **Clean UI**: Built with a modern, centered layout and custom styling for effortless readability.

## 🛠️ Built With

- **HTML5**: Semantic elements and structured layout.
- **CSS3**: Custom flexbox positioning, CSS media queries, and responsive styling.
- **JavaScript (ES6+)**: DOM manipulation and conversion logic.
